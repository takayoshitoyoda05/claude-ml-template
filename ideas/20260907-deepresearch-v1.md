# DeepResearch 相当機能のアイディア出し(発散 v1)

日付: 2026-09-07 / お題: Claude Code(このテンプレート)に、問いを受けて Web を
多段調査し引用つきレポートを返す DeepResearch 相当の機能を作る。

## 発散(15案)

### 形態系(前提を疑う)
1. **並列調査団**: リーダーが問いをサブクエスチョンに分解 → サブエージェント数体が
   各自 WebSearch/WebFetch で調査 → リーダーが統合(並列実装と同じトポロジーの調査版)
2. **Workflow 決定的パイプライン**: 「分解→並列検索→主張抽出→検証→執筆」を
   Workflow スクリプトとして決定的に組む
3. **反復深化型(単独)**: 検索→読む→新たな問い→再検索のループ。飽和または
   予算(検索回数上限)で停止。本家 DeepResearch に最も近い
4. **長時間自律型**: バックグラウンド+ScheduleWakeup で数時間規模。進捗を
   状態ファイル(SKILL.state)に記録し compact 耐性を持たせる
5. **多モデル合議調査**: Claude と Codex が独立調査し合議規約で統合
   (一致→確度高 / 矛盾→要深掘り)

### 検証規律系(逆転: 「1回検索して最初のヒットを信じる」の反転)
6. **二重ソース規約**: 各主張に独立ソース2つ必須。片方のみは「未確認」と明記
7. **反証検索の義務化**: 各仮説に支持クエリと反対クエリの両方を必ず投げる
   (refuter 文化。確証バイアス対策)
8. **引用の接地検証**: 執筆後に検証エージェントが各引用 URL を再取得し、
   主張がソースに実在するか照合(6.2 接地検証の調査版。引用ハルシネーション遮断)
9. **中間チェックポイント承認**: 調査方針サマリを中間で人間に提示(L2 承認文化)

### 入口・成果物系(組み合わせ)
10. **インタビュー駆動**: design-interview で調査要件(問い・スコープ・深さ・
    成功基準・除外範囲)を確定してから走らせる(調査の設計書)
11. **完全トレース成果物**: docs/research/<日付>/report.md + evidence/
    (URL・取得日時・引用スニペット・検索クエリログ)(report_gen 文化)
12. **Artifact 出力**: レポートを引用リンク付き Web ページとして公開

### 規模適応・資産化系(極端化)
13. **規模ルーティング**: router が調査規模を S/M/L 判定(S=単発検索で即答、
    M=1エージェント反復、L=並列調査団)
14. **literature-review の一般化**: 既存スキル(論文向け)を Web 全般に拡張する増築案
15. **知識の資産化**: 調査要点を CONTEXT.md / ideas/ に構造的に蓄積し、
    再調査時に前回資産から始める(調査の冪等化)
